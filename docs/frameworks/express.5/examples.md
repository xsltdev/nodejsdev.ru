# Примеры Express

На этой странице собран список примеров использования Express.

-   [auth](https://github.com/expressjs/express/tree/master/examples/auth) - Аутентификация по логину и паролю
-   [content-negotiation](https://github.com/expressjs/express/tree/master/examples/content-negotiation) - HTTP-согласование контента
-   [cookie-sessions](https://github.com/expressjs/express/tree/master/examples/cookie-sessions) - Работа с сессиями на основе cookie
-   [cookies](https://github.com/expressjs/express/tree/master/examples/cookies) - Работа с cookie
-   [downloads](https://github.com/expressjs/express/tree/master/examples/downloads) - Передача файлов клиенту
-   [ejs](https://github.com/expressjs/express/tree/master/examples/ejs) - Работа с шаблонами Embedded JavaScript (ejs)
-   [error-pages](https://github.com/expressjs/express/tree/master/examples/error-pages) - Создание страниц ошибок
-   [error](https://github.com/expressjs/express/tree/master/examples/error) - Работа с middleware обработки ошибок
-   [hello-world](https://github.com/expressjs/express/tree/master/examples/hello-world) - Простой обработчик запросов
-   [markdown](https://github.com/expressjs/express/tree/master/examples/markdown) - Markdown как движок шаблонов
-   [multi-router](https://github.com/expressjs/express/tree/master/examples/multi-router) - Работа с несколькими роутерами Express
-   [mvc](https://github.com/expressjs/express/tree/master/examples/mvc) - Контроллеры в стиле MVC
-   [online](https://github.com/expressjs/express/tree/master/examples/online) - Отслеживание активности пользователей через пакеты `online` и `redis`
-   [params](https://github.com/expressjs/express/tree/master/examples/params) - Работа с параметрами маршрутов
-   [resource](https://github.com/expressjs/express/tree/master/examples/resource) - Несколько HTTP-операций над одним ресурсом
-   [route-map](https://github.com/expressjs/express/tree/master/examples/route-map) - Организация маршрутов через карту
-   [route-middleware](https://github.com/expressjs/express/tree/master/examples/route-middleware) - Работа с route middleware
-   [route-separation](https://github.com/expressjs/express/tree/master/examples/route-separation) - Организация маршрутов по ресурсам
-   [search](https://github.com/expressjs/express/tree/master/examples/search) - Search API
-   [session](https://github.com/expressjs/express/tree/master/examples/session) - Пользовательские сессии
-   [static-files](https://github.com/expressjs/express/tree/master/examples/static-files) - Раздача статических файлов
-   [vhost](https://github.com/expressjs/express/tree/master/examples/vhost) - Работа с виртуальными хостами
-   [view-constructor](https://github.com/expressjs/express/tree/master/examples/view-constructor) - Динамический рендер представлений
-   [view-locals](https://github.com/expressjs/express/tree/master/examples/view-locals) - Сохранение данных в объекте запроса между вызовами middleware
-   [web-service](https://github.com/expressjs/express/tree/master/examples/web-service) - Простой API-сервис
