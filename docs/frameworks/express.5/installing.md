# Установка

Перед началом убедитесь, что у вас установлен [Node.js](https://nodejs.org/) версии 18 или выше. Затем создайте каталог приложения и перейдите в него.

```bash
mkdir myapp
cd myapp
```

Используйте команду `npm init`, чтобы создать для приложения файл `package.json`. Подробнее о том, как работает `package.json`, см. в [Specifics of npm's package.json handling](https://docs.npmjs.com/files/package.json).

```bash
npm init
```

Эта команда задаст ряд вопросов, например об имени и версии приложения. Пока можно просто нажимать RETURN, чтобы принять значения по умолчанию, кроме одного пункта:

```
entry point: (index.js)
```

Введите `app.js` (или любое другое имя главного файла). Если хотите оставить `index.js`, нажмите RETURN, чтобы принять предложенное имя.

Теперь установите Express в каталоге `myapp` и добавьте его в список зависимостей. Например:

```bash
npm install express
```

Чтобы установить Express временно и не добавлять его в список зависимостей:

```bash
npm install express --no-save
```
